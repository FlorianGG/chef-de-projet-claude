Scénarios du chef de projet

Trois parcours avec le plugin projet pour Claude Code, et qui fait quoi à chaque étape : toi, le chat claude.ai (conversation ou projet), Claude Code et GitHub.

Chat réfléchit→ GitHub décide→ Claude Code exécute→ Toi valides et merges

Tu veux…

BesoinOùCommande
Réfléchir à une idée floueChat—
Démarrer un projetClaude Code/projet:nouveau
Reprendre un projet existantClaude Code/projet:adopter
Ajouter une fonctionnalitéClaude Code ou Chat → issue/projet:fonctionnalite ou /projet:avancer <n°>
Faire avancer le travailClaude Code/projet:avancer
Essayer ce qui a été faitClaude Code/projet:essais
Clore une étapeClaude Code/projet:etape
Valider une modificationGitHubMerge (toi seulement)
