# Pièges connus généraux

Erreurs rencontrées sur de vrais projets, valables pour tous les projets, que les relecteurs doivent toujours savoir retrouver. Format : un dossier par piège (`piege.json`, `diff.patch`, `spec.md`), décrit dans `skills/orchestrateur/fichiers.md`.

Un piège entre ici uniquement par une PR, après acceptation par une personne (`/projet:pieges trier`, portée « général »). Rien n'y entre automatiquement.
